# VI — правила для агентов

## Модели

- **Fable** — только обсуждение и планирование, когда пользователь сам открыл такую сессию. Код на Fable не пишем, субагентов и workflow на Fable не запускаем.
- **Opus** — основная работа: реализация по спекам и планам, ревью.
- **Sonnet** — багфиксы и мелкие механические правки; поиск и чтение кода.

При запуске субагента или workflow всегда указывать `model` явно: `opus` для реализации, `sonnet` для багфикса, механики и поиска. Без параметра субагент наследует модель сессии, и в сессии Fable это самый дорогой вариант.

Спеки и планы пишутся так, чтобы исполнитель не изучал проект заново: точные пути файлов, интерфейсы, порядок шагов, команды проверки. Исполнитель читает план и названные в нём файлы, а не весь репозиторий.

## Работа

- `src/rules` — чистая детерминированная симуляция. Визуал, звук и интерфейс читают её состояние и события и никогда не влияют на правила.
- Визуальный стиль ведёт пользователь. Агент исполняет принесённый им слой и не придумывает внешний вид по своей инициативе.
- Проверка: `npm test`, `npm run typecheck`, `npm run build`. Дев-сервер — только через preview (`vi-dev` в `.claude/launch.json`, порт 5183).
- Работаем в `main`. Коммит и пуш — только после «ок» пользователя: пуш в `main` публикует сборку на GitHub Pages.
- В рабочем дереве лежат незакоммиченные правки других чатов: в коммит брать только свои файлы, без `git add -A`.
