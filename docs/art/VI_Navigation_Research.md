# VI — навигация и главное меню: как есть, как у других, что поменять

> Вид: исследование. Статус: в силе (ждёт слова владельца по разделу 7). Дата: 2026-11-05.
> Что заменило: —. Источник: игра в preview (сборка 0.2.102, `main` 53c6e53) на 360×640 и 1920×1080 с чистым хранилищем, код `src/shell` и `src/app/game.ts`, телеметрия Playgama в `src/levels/players.ts`, веб-поиск 5 ноября 2026.
> Что живёт в коде: src/shell/screens/menu.ts, src/shell/screens/start.ts, src/shell/panels.ts, src/app/game.ts. Код и вид этим документом не меняются.

Постановка владельца, 5 ноября 2026 ([слова](../VI_Owner_Words.md), раздел 10, пункт 3): «главное меню визуально сильное, но очень неудобное для использования ни на телефоне, ни на десктопе. также навигация внутри игры может быть сложная и непродуманная для игрока. это нужно изучить, поискать референсы в популярных веб и мобильных играх и сравнить с нами». Раньше, 4 ноября: «основное меню я считаю сложным и перегруженным».

**Коротко.** Вход у VI уже как у лучших: одно нажатие `START` — и игрок на доске. Плохо всё, что после: меню — единственный перекрёсток, а попасть в него можно только через паузу (3 касания), выйти из него обратно в игру нельзя ничем, кроме запуска файла; главное действие игрока — «играть дальше» — в меню не названо; на телефоне файлы — шесть костей в верхней трети экрана, по два касания на каждую, а легенда под ними, похожая на кнопки, не нажимается; на столе подписи у костей нажимаются, но ничего не запускают. Предложение — вариант А (S): меню остаётся картинкой, у него одна крупная команда «Продолжить · место N» внизу, легенда и подписи запускают файл с одного нажатия, Esc и «назад» возвращают в доску.

Снимки — в папке заметок сессии (вне репозитория, `side-session-notes/…/nav/`): `p01`–`p09` — телефон 360×640, `d01`–`d05` — стол 1920×1080. Ниже на них ссылки по имени.

## 1. Карта навигации как есть

### 1.1. Граф экранов

```

      │
      ▼
   START (доска под затемнением, одна команда)  p01 d01
      │ 1 касание
      ▼
   ДОСКА места N  ── HUD: звук · заново · пауза (угол), отмена (низ)  p02 d02

      ▼                                      ▼
   ОКНО МЕЖДУ ДОСКАМИ  p08                ПАУЗА  p03

    МЕНЮ ──────РЕКОРДЫ ·  ─НАЗАД──────  записей)                ─НАЗАД─────────┘

```

Что ещё в графе:

- **Сеанс вживую** — клетка `LIVE` в списке (запуск сразу) или окно после досок 16, 28, 43, 56, 71, 85, 92 с «Пропустить»; итог сеанса — `ЕЩЁ РАЗ · ДАЛЬШЕ · (УДВОИТЬ за рекламу) · МЕНЮ`.
- **Назад браузера и системный «назад» Android** игра не слушает: истории страниц нет (`pushState` и `popstate` — только в Телеграме, `src/platform/telegram.ts`). На своей странице «назад» уходит с игры; в рамке площадки — с её страницы.
- **Свернули вкладку или окно**: прогресс и партия Endless сохраняются, доска встаёт на паузу (`setAway` → `pause`); по возвращении — панель паузы, ещё одно касание. Партия уровня между запусками не хранится: игра откроется на `START` того же места, доска заново.
- **Новый игрок**: список уровней открыт целиком — все 100 мест и сеансы нажимаются с первого входа (`campaignCells` без замков); заметна только красная метка на клетке игрока.

### 1.2. Касания до цели

Телефон, палец; стол — мышь (на столе кость меню запускается с одного клика: наведение уже ставит на неё фокус). Считаются нажатия, свайпы хода не считаются.

| Откуда → куда | Телефон | Стол | Путь |
|---|---|---|---|
| **Холодный старт, новый или вернувшийся игрок** | | | |
| играть дальше (кампания) | **1** | **1** | START |
| выбрать другое место | 5 | 5 | START → пауза → МЕНЮ → УРОВНИ → клетка |
| Endless | 5 | 4 | START → пауза → МЕНЮ → кость Endless (×2 на телефоне) |
| сменить язык | 5 | 5 | START → пауза → НАСТРОЙКИ → ЯЗЫК → язык (+2 назад в игру) |
| выключить звук | 2 | 2 | START → кнопка звука в углу |
| в меню | 3 | 3 | START → пауза → МЕНЮ |
| **Из окна между досками** | | | |
| играть дальше | **1** | **1** | ДАЛЬШЕ |
| выбрать другое место | 5 | 5 | ДАЛЬШЕ → пауза → МЕНЮ → УРОВНИ → клетка (пауза в окне не открывается) |
| Endless | 5 | 4 | ДАЛЬШЕ → пауза → МЕНЮ → кость |
| сменить язык | 5 | 5 | ДАЛЬШЕ → пауза → НАСТРОЙКИ → ЯЗЫК → язык |
| выключить звук | 2 | 2 | ДАЛЬШЕ → звук |
| в меню | 3 | 3 | ДАЛЬШЕ → пауза → МЕНЮ |
| **Из меню** | | | |
| вернуться в доску, с которой ушёл | 2, доска заново | 2 | УРОВНИ → клетка (открыт на месте игрока); «вернуться» как действия нет |
| Endless | 2 | 1 | кость (первое касание только ставит фигуру) |
| **Из итога Endless** | | | |
| играть дальше в кампанию | 3 | 3 | МЕНЮ → УРОВНИ → клетка |

Время до первого хода нового игрока: загрузка (метка `game_loaded`, медиана 2,6 с по телеметрии до 4 ноября; boot убран, `START` встаёт на первом кадре со шрифтом) + одно касание `START` + первый свайп. Отдельной метки «первый ход» в телеметрии нет — его не мерили.

## 2. Что неудобно — с доказательством

Отдельно: **неудобно** — лишние нажатия, далеко, не работает то, что выглядит работающим; **непривычно** — иначе, чем у других, но учится за один раз.

| # | Что | Доказательство | Вид |
|---|---|---|---|
| 1 | В меню попадают только через паузу | 3 касания с доски; на экране доски пути в меню нет, кроме паузы (снимки p02, d02) | неудобно |
| 2 | Из меню нельзя вернуться в доску | у `MenuScreen` нет `back`: Esc ничего не делает; уход в меню прерывает попытку (`leaveRun`), вернуться — 2 касания и доска заново | неудобно |
| 3 | Главного действия в меню нет | «играть дальше» — не файл: надо понять, что «Уровни» → клетка с красной меткой; шесть файлов равны по весу (p04) — правило «одно главное действие на экране» нарушено | неудобно |
| 4 | Кость меню — два касания | первое касание только ставит фигуру (`confirm` в `input.ts`); в тесте касание по Endless оставило меню на месте | неудобно |
| 5 | Легенда выглядит как кнопки и не нажимается | строка выбранного файла залита, как команда (p04); касание по «БЕСКОНЕЧНЫЙ» — фигура осталась на «УРОВНИ» | неудобно |
| 6 | Кости на телефоне — в верхней трети | зоны y 89–301 из 640: дальняя для большого пальца зона (Хубер: 49% держат телефон одной рукой) | неудобно |
| 7 | На столе подписи нажимаются, но не запускают | клик по имени ставит фигуру; запустить — кость или полоса ИГРАТЬ в 500–950 px справа (d04); по Фиттсу путь от развёртки к полосе — ID ≈ 3,7 бита против 1 клика по кости | неудобно |
| 8 | Окно между досками ведёт только вперёд | из окна нет ни меню, ни списка; пауза в окне не открывается — 5 касаний до другого места | неудобно, но это и есть «одно главное действие»: цена — редкий путь |
| 9 | Кнопки доски в верхнем углу телефона | пауза, заново, звук — y 0–48 справа | непривычно: так у большинства игр, и нажимают их редко |
| 10 | `START` перед доской | лишнее касание до первого хода; Poki советует без титульного экрана | спорно: решение владельца 8 октября «одна, понятная, яркая»; касание открывает звук |
| 11 | Меню — развёртка кости, а не список | надо понять, что кости нажимаются (стрелки добавлены 6 октября: «не все понимают, что кости нажимаются») | непривычно; лицо игры — оставить |
| 12 | Слова-двойники с катаканой | `はじめる ИГРАТЬ`, `ポーズ ПАУЗА` | непривычно, решено владельцем 29–30 октября |
| 13 | «Назад» браузера и Android уходит с игры | истории нет | неудобно на телефоне, где «назад» — привычка |
| 14 | Список на столе — 11 клеток в ряд, а не 12 | 44 зоны мест при 1920×1080 (d05), [перечень](VI_Interface_Layer.md) пишет 12 | расхождение страницы и игры, не удобство |

Телеметрия о меню молчит: событий открытия меню и файлов нет. По доскам ([`players.ts`](../../src/levels/players.ts), 5 октября — 4 ноября): между досками почти никто не теряется (B01 прошли 40 — H06 начали 40; R03 прошли 70 — следующую начали 70), теряют на самих досках и после первой (R01 прошли 111, следующую по тогдашнему ряду начали 94). Ряд за месяц перестраивался, так что это сигнал, не замер.

**Что измерено:**

- Poki: игроки уходят к другой игре, если загрузка дольше 10 секунд; экранов и меню — минимум, лучше сразу в игру; `gameplayStart` — на первом вводе игрока ([требования качества](https://developers.poki.com/guide/requirements-quality)). Новичку — без заставки, титульного экрана и выбора уровня ([easy access](https://developers.poki.com/guide/easy-access)). Мерила Poki на своём трафике; числа конверсии на страницах нет. Цель «до игры доходят 65%+», которую повторяет [рыночное исследование](../VI_Web_Games_Market_Research.md), нашлась сейчас только в [руководстве Defold к SDK Poki](https://defold.com/extension-poki-sdk/best-practices), не у самой Poki.
- CrazyGames: загрузка меряется до первого `gameplayStart`, время в меню не засчитывается; порог проверки — 20 секунд до игры ([технические требования](https://docs.crazygames.com/requirements/technical)).
- Хубер, 2013, около 1 333 наблюдений на улице: 49% держат телефон одной рукой, 36% — в одной и нажимают другой, 15% — двумя; большой палец — около 75% касаний ([UXmatters](https://www.uxmatters.com/mt/archives/2013/02/how-do-users-really-hold-mobile-devices.php)). Цветная карта «зон пальца» из этого не следует напрямую.
- Размер цели: Apple 44 pt, Material 48 dp, WCAG 2.2 — 24 CSS px (AA) и 44 (AAA) — по пересказам, первоисточники не открывались.
- GameAnalytics, Q1 2024, 10 000+ мобильных игр: медиана D1 22,9%, D7 4,2% ([сводка](https://gamedevreports.substack.com/p/gameanalytics-benchmarks-in-mobile)); к навигации прямо не относится — мерка возврата.

**Мода, не доказано:** Play с номером уровня вместо карты (A/B не опубликованы); главная кнопка внизу (из Хубера, но не замер на играх); нижняя полоса вкладок; шестерёнка в верхнем углу; системный «назад» на Android ставит паузу (практика, а не требование Google в найденном); «красивое меню удерживает» — данных нет, Poki советует обратное.

## 5. Варианты

Вид остаётся за владельцем: ниже — порядок, расположение и число нажатий, не цвета и не рисунок. Развёртка кости как лицо меню сохраняется во всех трёх.

### А. Меню остаётся картинкой, главное действие одно и под пальцем — S

- Внизу меню всегда одна крупная команда **«ПРОДОЛЖИТЬ · МЕСТО 08»** (размер `START`), ведёт на место игрока. Полоса файла остаётся над ней обычной высоты.
- Легенда на телефоне и подписи на столе нажимаются и **запускают файл с одного нажатия**; кость — тоже с одного (выбор фигурой — только клавишами и стрелками записи).
- **Esc** в меню и «назад» браузера возвращают в доску, с которой пришли, без потери попытки (если пришли из паузы).
- Окно между досками не трогается.

- Чем мерить: касания (таблица 1.2); событие `menu_opened` / `menu_left{file}` в телеметрию Bridge — доля визитов меню, которые кончаются запуском, и какого файла.

### Б. Вход сразу в доску, меню — по кнопке и поверх доски — M

- Без `START`: первый кадр — доска с фигурой, звук открывается первым касанием (так уже устроено: `pointerdown` на окне). Если владелец оставляет `START` — Б без этого пункта.
- В HUD слева сверху — кнопка **меню** (≡); пауза остаётся справа. Меню открывается поверх затемнённой доски и закрывается Esc, «назад», нажатием вне меню — попытка не теряется.
- Пауза — 3 команды по слову 13 октября: ПРОДОЛЖИТЬ · ЗАНОВО · НАСТРОЙКИ; МЕНЮ из неё уходит в кнопку ≡.
- Окно между досками: ДАЛЬШЕ крупно, ЕЩЁ РАЗ, и мелким текстом под ними — «Уровни».
- «Назад» браузера закрывает верхнее окно (меню, панель), на доске — открывает паузу (одна запись истории на окно; на площадках проверить, что рамка это допускает).

### Предложение

**А сейчас, Б — вопросом владельцу.** А дешёвое, не трогает ни вход, ни решения о `START` и паузе и снимает претензии 2–7 раздела 2; первую — меню только через паузу — оставляет. Б даёт больше всего по главной мерке площадок — время и доля до первого хода, — но отменяет два слова владельца (`START` 8 октября и пауза 13 октября), поэтому только по его слову. В — если сеансы станут отдельным слоем: тогда у дома появится второе крупное дело, и полоса себя оправдает; без этого В — перестройка ради перестройки.

## 6. Что не доказано

- Что меню мешает игрокам на деле: событий меню в телеметрии нет; по доскам между ними почти не теряют, так что неудобство меню бьёт по редким путям — Endless, смена места, язык.
- Что отказ от `START` поднимет долю дошедших: у VI одна мерка `game_loaded`, метки «первый ход» в телеметрии нет; у Poki мерка общая для всех игр.
- Что «назад» браузера в рамке площадки можно забрать себе: зависит от рамки Playgama, CrazyGames, Яндекса — не проверено.
- Что двойное касание по кости путает людей: вывод из кода и пробы ботом-касанием, живых игроков не смотрели.
- Хубер и Фиттс — общие правила для телефонов и мыши, не замер на VI.
- Половина ячеек таблицы референсов — по общему знанию, не по источнику ([н]); экраны Royal Match, Candy Crush и Cut the Rope на Poki вживую не смотрели.
- Что «одна главная кнопка» лучше меню из нескольких файлов — так делают все девять, но A/B-чисел ни одна студия не публиковала.
