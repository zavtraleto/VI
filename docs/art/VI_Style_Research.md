# VI — исследование стиля: «найденная японская программа»

Дата: 2 октября 2026. Материал для обсуждения, не спецификация. Формула пользователя: **Japanese experimental CD-ROM + institutional software + PS1/PS2 system menus + cyber-occultism + digital hauntology**.

Дополняет [арт-документ v0.1](VI_Art_Direction_and_Signal_v01.md) и [логику мира](VI_World_Logic.md).

**Как соотносится с [VI_Shell_Research.md](VI_Shell_Research.md).** Тот документ — основной по виду оболочки: разбор присланных пользователем кадров, правила странности, три варианта меню. Этот шире оболочки: реальные опоры для лора, перебивки, игра, звук, язык программы. Где они расходятся, это отмечено в разделе 4.

## Принято пользователем 2 октября

1. **Японский — основной язык программы, свобода в языках.** Только значимые надписи; черновик словаря — в разделе 5, проверка носителем — позже. Это снимает вопрос 5 из VI_Shell_Research.md.
2. **Записи испытуемых 01–06 в RECORDS и их рекорды как пороги связи** (4.1, пункты 4 и 5). Распределение порогов — позже, по метрикам.
3. **Передача как файл в растущем окне** (4.3, пункты 1 и 2).
4. **Просачивания.** Предметы из передач появляются на фоне поля, перед сессией, вместо экрана загрузки. Редко, неожиданно, без помех игре; иногда случайно, иногда намеренно. После сессии — всегда намеренно: там сюжет.

Остальное в разделе 4 — по-прежнему предложения: дата последнего запуска на boot, знак с красным центром, итог как протокол опыта, подпись сессии, фиксированная сцена.

### Что из этого касается чата оболочки

- Надписи оболочки: японский крупно, английский мельче, пояснение на языке игрока — как слой перевода.
- Экран RECORDS: в таблице заранее стоят шестеро с датами по эре; игрок — 07.
- Рамка окна передачи рисуется средствами оболочки (`src/shell/kit.ts`, `theme.ts`), чтобы не нарушать единый слой интерфейса.

### План по перебивкам в игре

Отдельная задача, после задачи по виду поля (ей нужен слой фона за полем, который та задача создаёт):

- карточки передач как данные: сцена, вариант, настроение, сид, подпись, длительность, размер окна, условия;
- история просмотренного в настройках;
- распорядитель — чистая логика: после сессии следующая карточка сюжета (первая сессия, новый рекорд или давно не было), перед сессией — редкий короткий проблеск уже виденного, во время сессии — редкий предмет на фоне, случайно или сразу после большой цепочки;
- проигрыватель: окно-файл, размер из карточки; нажатие пропускает;
- вариант `echo` у каждой сцены: окружение растворено в цвете пустоты поля, виден только предмет;
- инструменты: показать карточку в лаборатории, сбросить историю.

## 1. Почему сейчас не ощущается

Текущие boot и меню (`?lab=shell`) — аккуратная современная типографика: тёплый бежевый фон, сглаженный гротеск в родном разрешении экрана, адаптивная сетка. Это читается как сайт-портфолио 2020-х. Чего нет:

- видимого пикселя и растровых шрифтов;
- японского текста;
- «тела» программы: рамок, заголовков окон, версий, копирайтов, серийных номеров, дат;
- следов того, что программой кто-то пользовался до игрока;
- материала носителя: ограниченной палитры, дизеринга, пререндеренных объектов;
- звука и характерного движения: смена кадра рывком, перерисовка, паузы загрузки.

## 2. Из чего состоит стиль

### 2.1. Японский экспериментальный CD-ROM (1991–1999)

Опорные работы: Eastern Mind и LSD: Dream Emulator (Осаму Сато), Gadget и L-Zone (Харухико Сёно), Cosmology of Kyoto, Garage: Bad Dream Adventure, игра Serial Experiments Lain для PS1.

Что из них берём:

- **Фиксированная сцена.** 640×480 (или 512×384), вокруг — чёрное поле. Ничего не подстраивается под окно.
- **8-битная палитра и дизеринг.** Градиенты видны как узор точек.
- **Пререндеренные объекты в пустоте.** Гладкие, медленные, без текстур игрового мира.
- **Видео в маленьком окне.** QuickTime 160×120 или 320×240 внутри кадра, с рамкой, а не на весь экран.
- **Смена кадра приёмами Director.** Пиксельное растворение, шторки, жёсткая склейка; никаких плавных кривых.
- **Программа как архив.** У Lain (PS1) игрок не «играет», а перебирает пронумерованные файлы базы данных: звук, видео, текст. У LSD после каждого сна — график, куда сон нанесён точкой.
- **Авторство, а не жанр.** Сато прямо говорил, что использует игровую платформу как средство для произведения искусства.

### 2.2. Институциональное ПО (Япония, 1990-е)

Windows 3.1/95 в японской версии, PC-98, рабочие станции лабораторий, текстовые сети (NIFTY-Serve, PC-VAN).

- **Растровый готик 12 и 16 точек** без сглаживания; полуширинная катакана (`ｾﾂｿﾞｸ`).
- **Системный серый**, объёмные фаски в один пиксель, строка состояния, заголовок окна.
- **Диалог с вопросом**: 「はい」/「いいえ」. Каждое действие — подтверждённая процедура.
- **Метаданные повсюду**: версия, сборка, имя файла в формате 8.3 (`SUBJ06.DAT`, `IMG0001.MOV`), объём памяти, номер формы.
- **Даты по эре**: 平成13年 = 2001. Одна такая дата сразу сообщает страну и время.
- **Красная круглая печать** (ханко) в графе «утверждено». Это тот же красный диск, что точка единицы и солнце.
- **Протокол эксперимента**: номер испытуемого, число проб, попадания, ожидание по случайности, отклонение.

### 2.3. Системные меню PS1 и PS2

- **PS1.** Менеджер карты памяти: сетка из 15 блоков, крошечные анимированные иконки, подпись сохранения японским текстом. Заставка — логотип на пустом фоне и один низкий аккорд.
- **PS2.** Тёмная синяя пустота с туманом, плавающие стеклянные кубы, часы из кристаллов, гул. Башни на заставке вырастают из истории карты памяти: по числу игр и по тому, сколько раз их запускали. Система показывает игроку его прошлое, ничего не объясняя.
- **Общее.** Мало пунктов, много пустоты, объект в центре, звук как половина впечатления.

### 2.4. Кибер-оккультизм

Оккультное приходит как схема и процедура, а не как символ.

- **Shin Megami Tensei.** Программа призыва демонов, распространяемая по сети. Ритуал — это запуск программы.
- **Serial Experiments Lain.** Реальная история науки (Ванневар Буш, Тед Нельсон, резонанс Шумана) смешана с вымышленными экспериментами над детьми.
- **Evangelion.** Каббалистическое древо как системная диаграмма; интерфейсы MAGI; титры: тяжёлый минчо (Matisse EB) белым по чёрному, скомпонованный углом.
- **Ccru и нумограмма.** Десять зон, сцепленных в пары с суммой девять. Нумерология выведена из самой десятичной записи, без заимствованных символов.
- **Вывод для VI.** Наша «нумограмма» уже есть: противоположные грани кости в сумме дают семь. Три пары (1–6, 2–5, 3–4) сходятся в центре, и центр — седьмой.

### 2.5. Цифровая хонтология

Призрак в носителе: будущее, которое не наступило, и следы тех, кого уже нет.

- **«Пульс» (Kairo, 2001).** Призраки приходят через сеть; низкое разрешение веб-камер; одиночество как главный ужас.
- **«Звонок».** Проклятая кассета — монтаж несвязанных зернистых кадров.
- **ITC, Клаус Шрайбер.** В 1980-х направлял камеру на телевизор без антенны, замыкая сигнал в петлю, и искал в шуме лица умерших.
- **Башни PS2.** Машина помнит.
- **Приёмы.** Следы прошлого пользователя; часы, остановившиеся на последнем запуске; файл, который не открывается; текст в сбитой кодировке.

## 3. Реальные опоры для лора

Эти вещи существовали. Институт в VI можно собрать из них почти без вымысла.

| Что | Когда | Чем полезно |
|---|---|---|
| Лаборатория ESPER в Sony (Ёитиро Сако, при поддержке Масару Ибуки) | около 1991–1998 | Японская корпоративная лаборатория, изучавшая экстрасенсорное восприятие и ци. Закрыта с формулировкой: явление есть, применения нет |
| Опыты Дж. Б. Райна в Дюке | 1930-е | Психокинез проверяли на игральных костях: может ли испытуемый повлиять на бросок |
| Лаборатория PEAR в Принстоне и Global Consciousness Project | 1979–2007; сеть с 1998 | Сеть генераторов случайных чисел по всему миру. Гипотеза: в моменты общего переживания случайность отклоняется |
| ITC и видеопетля Шрайбера | 1980-е | Контакт с умершими через изображение на экране |

Формула документа «случайность → паттерн → информация → контакт» — буквально метод Global Consciousness Project. Кости как прибор — буквально опыты Райна.

## 4. Предложения

Все — предложения для обсуждения.

### 4.1. Оболочка

1. **Фиксированная сцена с видимым пикселем.** Логическое разрешение 640×480 на широком экране и 480×640 в портрете, целочисленное увеличение, вокруг чёрное. Растровые шрифты без сглаживания.
2. **Японский — основной язык программы.** Крупно японский, мельче английский, совсем мелко — пояснение на языке игрока. Пояснение оформлено как слой перевода, наложенный эмулятором: другой шрифт, другая «рука».
3. **Тело программы.** Заголовок окна, строка состояния, версия, копирайт с годом, имена файлов, объём памяти.
4. **Следы прежнего использования.** На boot: дата последнего запуска в 2001 году и число прошедших дней. В RECORDS уже стоят результаты испытуемых 01–06 с датами по эре. Игрок — 07, не зарегистрирован.
5. **Рекорды как пороги.** Превзошёл результат испытуемого — он выходит на связь. Счёт, рекорды, шестеро и передачи становятся одной системой.
6. **История игрока как объект.** По примеру башен PS2: в меню растёт что-то, собранное из его сессий.
7. **Процедура.** Перед сессией — диалог 「接続を開始しますか？」 с «да» и «нет». Позже диалог может измениться.
8. **Движение.** Перерисовка сверху вниз, жёсткие склейки, пиксельное растворение, пауза «чтения диска».
9. **Цвет.** Тёмная трубка с одним светящимся тоном, как предложено в [VI_Shell_Research.md](VI_Shell_Research.md): это прямо следует из присланных кадров (Lain, PS2, PC-98).

Расхождения с VI_Shell_Research.md, которые решает пользователь:

- **Японский текст.** Там он под запретом до отдельного решения; здесь предлагается сделать его основным языком программы (пункт 2). Без него «японская программа» держится только на косвенных признаках.
- **Сцена.** Там — низкое разрешение на сетке знакомест во всё окно; здесь — фиксированная сцена с чёрным полем вокруг (пункт 1). Совместимо: сетка знакомест внутри фиксированной сцены.

### 4.2. Знак

Шесть узлов по кругу и красный центр. Узлы соединены через центр попарно: 1–6, 2–5, 3–4. Это схема кости, а не заимствованный символ. Она же — индикатор шести каналов в игре.

### 4.3. Перебивки

1. **Передача как полученный файл.** Открывается в окне с заголовком `IMG0001.MOV`, счётчиком времени и размером. Нынешний вид кадра сохраняется.
2. **Размер окна растёт с контактом.** Сначала маленькое окно внутри программы, на высоком контакте — во весь экран, затем за пределы рамки.
3. **Несколько окон сразу**, как в The Silver Case: кадр, текст и схема открываются и закрываются по ходу показа.
4. **Карточка перед кадром.** Номер и одно слово: тяжёлый шрифт с засечками, белым по чёрному. Голос той стороны.
5. **Видеопетля.** Эффект обратной связи в шейдере слоя для пиков контакта: изображение уходит само в себя.

### 4.4. Игра

1. **HUD как показания прибора.** Растровый шрифт, подписи на японском и английском.
2. **Итог как протокол опыта.** Пробы, попадания, ожидание по случайности, отклонение. Печать в графе.
3. **Подпись сессии.** Шесть линий — по одной на канал: сплошная, если канал в этой сессии замыкался достаточно часто, разорванная, если нет. 64 возможных рисунка, по одному на сессию.

### 4.5. Звук

Половина ощущения «найденного» — звук: аккорд запуска, раскрутка диска, щелчки интерфейса, тон комнаты. Сейчас вне задач, но без него эффект неполный.

## 5. Словарь оболочки (черновик)

Все формулировки требуют проверки носителем языка.

| Японский | Значение |
|---|---|
| 起動中 | запуск |
| メモリチェック | проверка памяти |
| 接続装置が見つかりません | устройство связи не найдено |
| エミュレーションモード | режим эмуляции |
| 被験者07 未登録 | испытуемый 07, не зарегистрирован |
| 現在の接続：なし | текущее соединение: нет |
| プロトコル | протокол |
| 演習 | упражнение |
| 記録 | записи |
| 設定 | настройки |
| 受信資料 | полученный материал |
| 前回起動　平成13年3月21日 | последний запуск: 21 марта 2001 |
| 読み込み中 | загрузка |
| 接続を開始しますか？ | начать соединение? |
| はい / いいえ | да / нет |

## 6. Шрифты

- Растровый готик с японским и кириллицей: DotGothic16 (уже подключён), PixelMplus 10 и 12 (лицензия M+, свободная).
- Тяжёлый минчо для голоса той стороны: открытые замены Matisse EB — Shippori Mincho B1, Zen Old Mincho, Noto Serif JP. Для кириллицы и латиницы остаётся Forum.
- Японские шрифты тяжёлые: в сборку брать только используемые знаки.

## 7. Чего не делать

- Не покрывать всё помехами: CRT и VHS поверх современной вёрстки не делают её старой.
- Не использовать японский как узор: только значимые надписи.
- Не цитировать чужие логотипы, интерфейсы и названия: берём приёмы, а не узнаваемые элементы.
- Не делать основное действие нечитаемым: игрок должен найти запуск за пару секунд.
