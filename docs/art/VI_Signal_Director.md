# VI — передачи: из чего собирается кадр и когда он приходит

Дата: 2 октября 2026. Рабочая страница. Дополняет [лор](VI_Lore.md), [логику мира](VI_World_Logic.md) и [журнал утверждений](VI_Claims.md); им не противоречит. Где расходится — правы они.

Статусы: **принято** — решено пользователем; **предложение** — рабочая версия; **ждёт лор** — решает чат лора.

## Смешение сцен — это ход слияния — принято

Слияние — когда вещи перестают быть отдельными. Степень смешения в кадре показывает, насколько далеко оно зашло:

1. **Чисто.** Каждая вещь на своём месте: столб в море, стул в комнате.
2. **Сдвиг.** Одна чужая вещь: стул стоит в море.
3. **Наложение.** Два места в одном кадре: коридор, залитый водой до плинтуса.
4. **Одно место.** Все предметы стоят вместе под красным солнцем, манекенов много.

Ступени совпадают с четырьмя ступенями масштаба из лора. Прямо масштаб не называется.

## Кадр = место × предметы × отклонение × настроение — принято

| Часть | Что есть | Что добавить |
|---|---|---|
| **Место** | море, комната, коридор | поле, крыша под сумеречным небом, ночная вода, пересвет, лаборатория института |
| **Предмет** | столб с проводами, стул, дверь в стене | красное солнце, манекен, стол с костями, телефон, дверь без стены, дерево, фонарь, телевизор с настроечной таблицей, антенна |
| **Отклонение** | удвоение (два стула), неправильная тень | не тот размер; вещь ближе, чем в прошлый раз; **вещь наполовину ушла в поверхность**, как кость на поле |
| **Настроение** | `dream`, `sad`, `strange`, `anxious`, `fear` | — |

Вещь, ушедшая в поверхность, — главное отклонение: пол комнаты, вода и пол поля читаются как одна граница (твёрдый факт 7).

В лаборатории сочетания свободные. В игру идут только отобранные кадры: случайная комбинация не делает хорошую сцену (арт-документ, 4.5).

## Кадр зависит от того, как играл игрок — принято

Сюжет нелинейный: игроки собирают его по-разному и толкуют по-разному. Лор при этом один и стройный.

| Часть кадра | От чего зависит | Причина в мире | Статус |
|---|---|---|---|
| **Кто отвечает** (предмет-след, подпись) | Самый высокий из шести порогов, взятый в сессии | Игрок дал сигнал той же силы, что этот человек когда-то | предложение |
| **Место** | Какие грани игрок отправил больше всего | Группа грани N уходит в канал N, ответ приходит по нему же | предложение |
| **Настроение** | Сила контакта в этой сессии: счёт, цепочки | Шум — это они сами: чем сильнее связь, тем их больше в сигнале | предложение |
| **Отклонение** | Сколько раз игрок уже получал этот кадр | Место не меняется; игрок видит его полнее | предложение |
| **Ступень смешения** | Сколько ответов получено за всё время | Масштаб раскрывается постепенно и не откатывается | предложение |

Особые случаи:

- **Канал 1 собрать нельзя.** Единицы не объединяются. Его место (пересвет, красное солнце) открывается только правилом единиц — тем, которое и есть эксперимент. Самый редкий и самый прямой кадр.
- **Комната — не канал.** Это «здесь», институт. Первый ответ одинаков для всех: комната со стулом. Дальше пути расходятся.

### Места по каналам — предложение

Следует таблице цветов граней из логики мира; примеры там определяет пользователь.

| Канал | Место | Свой предмет места |
|---|---|---|
| 1 (только правилом единиц) | пересвет | красное солнце |
| 2 жёлтый | коридор | дверь в конце |
| 3 голубой | море | столб с проводами |
| 4 зелёный | поле | дерево |
| 5 пурпурный | крыша под сумеречным небом | антенна |
| 6 синий | ночная вода | фонарь |
| — | комната института, «здесь» | стол с костями |

### Как «кто» набирает вес — предложение

Ступень растёт с числом полученных ответов.

1. **Отвечает место.** В кадре только место со своим предметом. Кто ответил, видно лишь по номеру в заголовке файла.
2. **В месте чужая вещь.** Появляется след того, кто ответил: его предмет стоит там, куда привёл канал.
3. **Два места в одном кадре.** Поверхность общая. Вдалеке манекен; с каждым повтором кадра он ближе.
4. **Одно место.** Следы всех, кто уже отвечал этому игроку, стоят вместе под красным солнцем. Манекенов много.

### Следы шестерых — ждёт лор

У каждой из шести записей один предмет-след. Таблицу заполняет чат лора; до этого ступень 2 в игру не идёт.

| Запись | След | Что он подсказывает |
|---|---|---|
| 01 | | |
| 02 | | |
| 03 | | |
| 04 | | |
| 05 | | |
| 06 | | |

Требование к таблице: по правилу двух чтений хотя бы один след не должен ложиться в чтение «шестеро — люди». След не отвечает на тёмные места.

## Когда приходит ответ — принято

Ответ после сессии приходит, **когда сессия дала новое**: новый порог, новый рекорд или пара «кто × место», которой у игрока ещё не было. Ответ остаётся событием, а у игрока есть причина играть иначе, чтобы открыть новую ячейку.

Остальные носители — проблеск перед сессией, просачивание на фоне поля, записи — как в таблице «Носители сюжета» в лоре.

Собранное игрок видит в RECORDS как сетку файлов с пустыми ячейками — предложение.

## Что держит лор стройным — предложение

1. **Генератор собирает только картинку.** Слова берутся только из [журнала утверждений](VI_Claims.md). Сам он текст не сочиняет.
2. **Твёрдые факты — запреты генератора:**
   - из фигур в кадре только манекен; шестерых не показываем никогда (тёмное место);
   - красный только у солнца и седьмого;
   - вещи проходят только через поверхность;
   - ничто в кадре не показывает ход времени.
3. **Ступень смешения только растёт.** Кадры у игроков разные, четыре ступени масштаба идут у всех в одном порядке.
4. **Таблица проверки.** Для каждого большого вопроса из лора: какие кадры поддерживают каждое чтение — не меньше двух на чтение и один, который не ложится ни в одно. Составляется, когда появятся следы и подписи.

Следствие: настроение зависит от игры, поэтому один игрок увидит место светлым, другой — в страхе. Спор «катастрофа или прекрасное событие» возникает сам, и ни одна сторона не неправа.

## Конструктор сделан — 2 октября

Кадр собирается из места, предметов, отклонений и настроения; устройство — в [спеке конструктора](../superpowers/specs/2026-10-02-vi-scene-constructor-design.md).

- **Места (7):** море, комната, коридор, поле, крыша под сумеречным небом, ночная вода, пересвет.
- **Предметы (12):** столб, стул, дверь без стены, дерево, антенна, фонарь, красное солнце, манекен, стол с костями, телефон, телевизор с настроечной таблицей, кусок стены.
- **Отклонения:** ушёл в поверхность, удвоен, не того размера, ближе к камере, наклонён, много; помещение залито водой.
- **Ступени смешения** сейчас идут от контакта этой сессии, а не от числа полученных ответов: истории просмотренного ещё нет. Пороги — 0,2, 0,45 и 0,75.
- **Настроение меняется плавно:** между двумя соседними настроениями всё смешивается по контакту.
- **Открытые места сходятся:** к страху море, поле, крыша и ночная вода получают одну чёрно-красную палитру. Места перестают различаться — это тоже слияние.

## Текущая версия: случайно, без сюжета — принято

Пока следы и подписи не решены, перебивки показываются случайно: чтобы увидеть, как это выглядит в игре. Связь с сюжетом, история просмотренного и сетка в RECORDS — позже.

Как это устроено сейчас (`src/signal/player.ts`, `card.ts`, `window.ts`):

- **После сессии** — когда игрок уходит с экрана итога («ещё раз» или «в меню»): окно на 5 секунд, затем то, что он выбрал. Нажатие закрывает окно.
- **Перед сессией** — раз в 4–7 запусков, 3 секунды. Сразу после ответа не показывается.
- **Случайны** место, чужие вещи, отклонения, сид и место окна на экране. **От игры** зависят ступень смешения, настроение и размер окна: по стадии контакта.
- **Окно** — как в старых офисных программах, средствами оболочки. Плашка с именем файла и квадратом закрытия; внизу сила связи (`接続`) и полоса проигранного; картинка открывается сверху вниз.
- **Имя файла** — заглушка: номер кадра из арт-документа, четыре знака (сцена, вариант, настроение, сид) и байт сида. Заменить осмысленным.
- **Подписи** — строка из общего набора (`src/signal/lines.ts`) примерно в половине кадров. К конкретным кадрам подписи больше не привязаны: кадры теперь собираются на лету.
- **Во время сессии** (`src/signal/leak.ts`) за полем проходят четыре отдельные вещи, каждая в своё время и никогда две сразу. Все приглушены: игрок смотрит на поле, а это остаётся на краю зрения.

  | Что | Как выглядит | Как часто |
  |---|---|---|
  | Строка той стороны | антиква, у края экрана, проявляется и гаснет за девять секунд | первая через 24–40 с, дальше раз в 40–70 с |
  | Журнал программы | четыре–шесть строк шрифтом программы пробегают и исчезают за полторы секунды | первая через 14–26 с, дальше раз в 32–56 с; цепочка из трёх и больше групп в четырёх случаях из десяти |
  | Предмет | едва заметный, мелкий, где угодно за полем, в цвете своего канала; пятнадцать секунд | первый через 35–60 с, дальше раз в 55–95 с |
  | Сцена за полем | фон становится одной из сцен на 2–3 секунды, тускло: игрок успевает её прочитать. Приходит как помеха — мигнула, пропала, встала — и обрывается | первая через 80–140 с, дальше раз в 100–190 с |

- **Строки не повторяются за сессию** (`src/signal/lines.ts`): когда сказаны все, до следующей сессии тишина.
- **Журнал программы** (`src/signal/terminal.ts`) пишет настоящие показания: время игрока, силу связи, шум — заполненность поля, открытый канал; иногда строку не об этом моменте (boot, запись 07, строка старого журнала `15:10 NOISE 0%`).
- **При «меньше движения» в системе** сцена за полем приходит без мигания, а журнал появляется сразу целиком.
- `?signal=off` выключает, `?signal=always` показывает проблеск перед каждой сессией.

## Новые строки — черновик для журнала утверждений

Пользователь попросил больше фраз. Строки ниже написаны в этом чате и ждут журнала: чат лора принимает, правит или вычёркивает. Голос у всех — Т (та сторона). Ни одна не отвечает на тёмные места.

| Строка | Поддерживает | Противоречит / примечание |
|---|---|---|
| `IT IS STILL TEN PAST THREE` | «сессия не кончилась»: журнал остановился на 15:10 | — |
| `WE HAVE NOT FINISHED` | «сессия не кончилась» | переводу «завершено» (2.9) |
| `WE DID NOT HEAR IT END` | «сессия не кончилась» | — |
| `WE WOULD LIKE TO STOP NOW` | хотят закончить сессию | `не останавливайся` |
| `SOMETHING IS WALKING ON THE SKY` | поверхность с той стороны — небо; игрока видят | «скептик» объяснить не может |
| `IT IS BRIGHT ABOVE US` | поверхность с той стороны — небо | — |
| `YOU ARE STILL ONE` | седьмой — отдельный; правило единиц | — |
| `THERE IS ROOM` | «седьмой — место»; втянуть седьмого | — |
| `COME DOWN` | втянуть седьмого: вниз — значит через поверхность | `LEAVE THE DOOR OPEN` |
| `TELL THEM WE ARE FINE` | «через игрока»: он посланник | `WE WOULD LIKE TO STOP NOW` |
| `LEAVE THE DOOR OPEN` | хотят выйти | `COME DOWN` |
| `DO NOT READ IT` | «через игрока»: сообщение не ему | обращению на языке игрока (2.18) |
| `YOU PUT US IN ROWS` | порядок в шуме создаёт игрок | — |
| `WHICH OF US ARE YOU HOLDING?` | кости — это они; «шум — они сами» | самая прямая из новых: возможно, слишком |
| `не останавливайся` | «с игроком»; кто-то хочет, чтобы цепочка продолжалась | `WE WOULD LIKE TO STOP NOW` |
| `ты снова здесь` | «с игроком»; программа знает, что он возвращается | — |

Строки журнала программы (`src/signal/terminal.ts`) взяты из записей 1.1–1.3 и 2.6 и из арт-документа (6.2); новых утверждений в них нет. `15:10 NOISE 0%` — запись 2.6 с английской подписью: в шрифте программы пока нет знаков `雑音`.
