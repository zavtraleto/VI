# VI — обучение на уровнях: решения, лестница уроков, требования к доскам

Дата: 5 октября 2026 · **С 6 октября лестницу уроков этой страницы заменили вводный курс и уроки по главам: [спека](superpowers/specs/2026-10-06-vi-levels-onboarding-design.md). Словарь (раздел 2), как ходит игрок (раздел 3) и замеры (раздел 7) действуют.** · Статус: порядок уроков, словарь и голос окон приняты владельцем 5 октября; опубликовано по его слову в версии 0.2.13. 6 октября по его замечаниям окна переписаны голосом лаборанта, буквы увеличены, печать озвучена; нынешние уровни по его слову не трогаются, лестница уроков из раздела 4 ждёт. Формулировки окон — исполнителя, правит владелец ([журнал утверждений](art/VI_Claims.md), раздел «Уровни: окна правил»). Доски под уроки подбирает задача «Генерация» по разделу 5; пока их нет, в игре стоит прежняя лестница из 23 уровней.

Откуда задача — [VI_Levels_Backlog.md](VI_Levels_Backlog.md), раздел 4, блок B. Правила уровней — [VI_Levels_First20_Build.md](VI_Levels_First20_Build.md). Исследование об обучении — [VI_Tutorial_Research.md](VI_Tutorial_Research.md).

## 1. Решения владельца (5 октября)

| Что | Решение |
|---|---|
| Словарь | «Комбо» — N костей с гранью N рядом. «Цепочка» — комбо, к которому докатывают кости, пока оно уходит |
| Порядок механик | Простые перекаты → ходьба по собранному комбо → цепочка → пол: как на нём оказаться, толчок, подъём наверх → сочетания. Новое вводится по одному |
| Удержание цепочки | Объяснить окном перед уровнем: как работает и сколько ходов даёт. Дать уровень, где игрок поймёт его сам |
| Число ходов над уходящим комбо | Не делать. «Счётчики в игре сейчас меня скорее бесят, но я понимаю их пользу. С ними будем разбираться позже» |
| Перечитать правила | Команда `RULES` в паузе уровня |
| Длина первой главы | 11–12 уровней вместо 8 |
| Голос окон | Начинает лаборант, и постепенно, едва заметно, говорить начинает кто-то другой, с той стороны |
| Тексты окон (6 октября) | Живой лаборант: здоровается, называет программу, вспоминает опыты Райна; язык человеческий, правило понятно ребёнку. Вводный курс ведёт он один; чужие слова проступают после курса, в главах |
| Нынешние уровни (6 октября) | «Пока не будем трогать существующие уровни»: меняются только размер текста и сам текст |
| Реплика после уровня, звук | Реплики лаборанта в окне итога не нужно. Звук печати нужен, «подходящий к лору и нашему саунддизайну» |
| Уровень 2 | Уроки «шаг — не ход» и «по уходящему комбо можно ходить» слиты в один: так предложил исполнитель, владелец принял таблицу без возражений. Вернуть раздельно — одно слово владельца |

Из задачи «Прогрессия» (решения владельца от 5 октября, версия 0.2.12; страница — [VI_Levels_Progression_Research.md](VI_Levels_Progression_Research.md)):

- Уровень, который нельзя проиграть, — только первый в главе. На втором уровне главы костей больше, чем на одно комбо.
- Три звезды даются за прохождение в пределах одного хода сверх наименьшего числа, две — ещё до трёх ходов, одна — за любое. Наименьшее число ходов игроку не называется нигде: тексты окон его не упоминают.
- У уровня есть щедрый лимит ходов; в шапке стоят сделанные ходы и предел.

## 2. Словарь

Игроку говорим четыре слова. Остальные — служебные, в текстах игры их нет.

| Слово | Что значит | Кому |
|---|---|---|
| комбо | N костей с гранью N, стоящих рядом; уходит | игроку |
| цепочка | комбо и кости, докаченные к нему, пока оно уходит | игроку |
| ход | перекат или толчок кости; только ход двигает мир | игроку |
| шаг | переход игрока с кости на кость или по полу; ходом не считается | игроку |
| звено | кость, докаченная в цепочку | служебное |
| удержание | ход, который звено даёт уже уходящим костям | служебное |
| стекло | уходящая кость: по ней можно прокатиться | служебное |
| причал | свободная клетка рядом с уходящим комбо | служебное |
| рабочая грань | грань, которая в этой главе делает комбо; остальные перечёркнуты | служебное |

## 3. Как ходит игрок на уровне

Справка по коду (`resolveMove` в `src/rules/movement.ts`, `floorStep` и `isDock` в `src/rules/board.ts`, настройки уровня в `levelConfig`, `src/rules/level.ts`). На неё опираются тексты окон.

| Где стоит игрок | Куда | Что происходит | Ход? |
|---|---|---|---|
| на стоящей кости | в пустую клетку | перекат своей кости | да |
| | на стоящую кость | шаг | нет |
| | на уходящую кость | перекат по ней: она исчезает сразу; совпала грань — своя кость встала в цепочку | да |
| на уходящей кости | на любую кость | шаг. Со стоящей кости обратно шагом не вернуться: только перекатом | нет |
| | в пустую клетку | сойти на пол | нет |
| | — | кость ушла: игрок на полу | — |
| на полу | в пустую клетку | шаг | нет |
| | в уходящую кость | подняться на неё | нет |
| | в стоящую кость, за которой свободно | толчок: кость едет, не поворачиваясь | да |
| | в стоящую кость, за которой край или стоящая кость | подняться на неё | нет |
| на полу в клетке рядом с уходящим комбо | в стоящую кость | подняться на неё, даже если её можно толкнуть | нет |

Комбо уходит два хода. Кость, вставшая в цепочку, уходит свои два хода и даёт всем уже уходящим костям ход, на котором они не опускаются. Со слов владельца: докатил на первом ходу — у комбо снова два хода, на втором — один.

## 4. Лестница уроков

26 уровней: глава троек — 11, глава двоек и троек — 8, глава пятёрок — 7. Окон десять. Знаков на поле новых нет.

| Место | Правило | Чем учит доска | Окно | Знак на поле |
|---|---|---|---|---|
| **1** | Комбо: три тройки рядом уходят; остальные грани не работают | две тройки стоят, третья в одном перекате | `lessonThrees` | стрелка первого хода, «2/3», кресты |
| **2** | Ходьба: шаг ходом не считается; по уходящему комбо можно пройти и сойти с него | шесть костей, два комбо по очереди; ко второму путь лежит по первому | `lessonWalk` | счёт ходов в шапке; отметка шага без возврата на печати — с этого уровня |
| **3** | Цепочка: к уходящему комбо докатывают ещё кость | четыре кости: без цепочки тупик | `lessonLink` | рамки клеток у уходящего комбо |
| **4** | Удержание: каждая кость в цепочке даёт комбо ещё ход | кратчайший путь идёт через удержание | `lessonHold` | — |
| 5 | Длинная цепочка, повтор | шесть костей: комбо и три кости по одной за ход | нет | — |
| **6** | Пол: кость ушла — игрок на полу; с пола кость толкают | без толчка не пройти | `lessonFloor` | — |
| **7** | С пола наверх | две кучки костей: ко второй путь лежит по полу, и подняться надо, не толкая | `lessonClimb` | рамки клеток у уходящего комбо |
| **8** | Правило семи: под четвёркой тройка | есть кость с четвёркой сверху | `lessonSeven` | печать |
| 9 | Сочетание: цепочка и правило семи | — | нет | — |
| 10 | Сочетание: пол и цепочка; ловушки | — | нет | — |
| 11 | Пик главы | тесная доска, очищается целиком | нет | — |
| **12** | Двойки и тройки | на доске и пара, и тройка | `lessonTwos` | с двоек сняты кресты |
| 13 | Повтор; считать кости | — | нет | — |
| **14** | По уходящей кости можно прокатиться | кратчайший путь идёт по уходящей кости | `lessonGlass` | рамка клетки, по которой прокатились |
| 15–18 | Сочетания и ловушки, один уровень с толчком | — | нет | — |
| 19 | Пик главы | тесная доска | нет | — |
| **20** | Пятёрки | четыре пятёрки стоят, пятая в одном перекате | `lessonFives` | «4/5», кресты |
| 21–25 | Сочетания | — | нет | — |
| 26 | Пик главы | тесная доска | нет | — |

Что остаётся без слов: шаг без возврата (отметка на печати), тупик (его называет окно проигрыша числами: сколько костей осталось и сколько нужно на комбо).

## 5. Требования к доскам — для задачи «Генерация»

Общее:

- Ключи уроков: место 1 — `lessonThrees`, 2 — `lessonWalk`, 3 — `lessonLink`, 4 — `lessonHold`, 6 — `lessonFloor`, 7 — `lessonClimb`, 8 — `lessonSeven`, 12 — `lessonTwos`, 14 — `lessonGlass`, 20 — `lessonFives`. Стрелка первого хода — только место 1. Ключ `lessonStep` уходит вместе с прежней лестницей.
- На местах 1–7 нет костей, которые стартуют рабочей гранью вниз (в главе троек — четвёркой вверх): правило семи не должно требоваться раньше, чем сказано.
- На уровне с окном приём урока — единственный новый. Приёмы, которых ещё не объясняли, кратчайшему решению не нужны.
- Уровень с окном проходят слабые игроки: персона «спешащий» — не реже 50% попыток, «обычный» — не реже 80%. Сейчас место 2 — 20% и 30%.
- Проиграть нельзя только на местах 1, 12 и 20. На остальных костей больше, чем на одно комбо.

По местам:

| Место | Доска | Что обязано выполняться | Как проверить |
|---|---|---|---|
| 1 | 3×3, 3 кости | две тройки стоят рядом, третья кость под игроком; один ход | как нынешнее место 1 |
| 2 | 3×3 или 4×4, 6 костей, одна кучка | два комбо по очереди; решается без цепочки за то же число ходов; без пола и без переката по уходящей кости; первый ход — костью, до которой надо дойти; 2–4 хода | решатель с запретом `link` даёт то же число ходов; `ownFirst` ложно |
| 3 | 3×3, 4 кости | без цепочки не решить; без пола и стекла; 2–3 хода | `needs: ['link']`, как нынешнее место 3 |
| 4 | 3×3, 5 костей, или 4×4, 6 | с удержанием путь короче, чем без него; в цепочке не меньше двух докаченных костей; без пола | решатель на той же доске с `liftMoves: 0` даёт больше ходов; `bestChain` не меньше 3 |
| 5 | 4×4, 6 костей | цепочка из четырёх: комбо и три кости по одной за ход; без пола | `bestChain` не меньше 4; `needs: ['link']` |
| 6 | 4×4, 5–6 костей | без толчка не решить; на пол игрок попадает сам — кость под ним уходит или он сходит; 4–6 ходов | `needs: ['floor']`, и в решении есть ход с пометкой `p` |
| 7 | 4×4, 6 костей, две кучки | ко второй кучке нет пути по костям; игрок поднимается на кость с пола и катит её; толчок решению не нужен | `needs: ['floor']`; в решении есть перекат кости, до которой дошли по полу, и нет ходов с пометкой `p` |
| 8 | 3×3, 4 кости | хотя бы одна кость стартует с тройкой снизу; новых приёмов нет; 3–5 ходов | число костей с верхом `7 − рабочая грань` больше нуля |
| 9–10 | 4×4, 6–7 костей | сочетания пройденного; жадный бот кончает тупиком в 30% прогонов и чаще | как нынешние места 6–7 |
| 11 | 3×3, 7 костей, или 4×4, 9 | тесная доска | как нынешние места 7–8 |
| 12 | 3×3, 5 костей | на доске и пара, и тройка; 2–3 хода | как нынешнее место 9 |
| 14 | 4×4, 6 костей | кратчайшее решение идёт по уходящей кости | `shows: ['glass']`, как нынешнее место 11 |
| 20 | 4×4, 5 костей | четыре пятёрки стоят, пятая в одном-двух перекатах | как нынешнее место 17 |

Чего нельзя обязать доской (замеры — раздел 7):

- **Удержание.** Доски, которую без него не пройти, не нашлось: 0 из 470. Досок, где с ним путь короче, — 36 из 470. Место 4 удержание показывает, а не требует. Оценка его тоже не обяжет: три звезды даются и за ход сверх наименьшего числа, а доски, где без удержания путь длиннее на два хода и больше, не нашлось ни одной (0 из 427 малых). Удержание остаётся правилом, которое помогает и которым можно не пользоваться: его объясняет окно, а место 4 даёт доску, где кратчайший путь идёт через него.
- **Перекат по уходящей кости.** То же, что было: 0 досок из 2000.

Проверок «без удержания», «рабочая грань снизу» и «толчок или подъём» в отборе пока нет. Числа для них печатает `node scripts/teach.mjs`.

## 6. Тексты окон

Тексты — в `src/ui/i18n.ts` (русский и английский) и в `src/ui/lang/` (ещё пять языков): ключи `lesson*` (что говорит лаборант перед уровнем), `rule*` (памятка для `RULES`) и `levelStuck`. В [журнале утверждений](art/VI_Claims.md) они записаны по одному, с уровнем и с тем, что выдаёт каждая строка. Чего держатся тексты:

- говорит человек: здоровается, шутит, объясняет причину («костей четыре, а тройке нужны три»); правило при этом сказано прямо и простыми словами;
- сообщение — одна мысль; сообщений на урок не больше четырёх, в сообщении не больше 230 знаков на любом из семи языков (проверяет тест), чтобы оно помещалось в окно телефона;
- слова игрока — «комбо», «цепочка», «ход», «шаг»; рабочие грани объясняются каналами («сегодня открыт третий канал»);
- числа названы числами: «два хода», «ещё один ход»;
- первая глава — лаборант целиком; дальше в сообщении бывает одно-три слова той стороны, в тексте они в квадратных скобках (`messagesOf` в `src/levels/voices.ts`), на экране не отмечены и отличаются только звуком;
- памятка `rule*` — правило одной-двумя строками без говорящего: её читают посреди уровня.

Уроки нынешней лестницы несут больше одного правила, потому что уровни не трогаются: окно уровня 3 говорит и о ходьбе по уходящему комбо, и о цепочке, и о ходе, который даёт каждая кость в цепочке; окно уровня 13 — и о поле, и о подъёме с него.

## 7. Замеры

На 23 досках нынешней лестницы (`node scripts/teach.mjs`):

- До уровня 7 нет ни одной кости с рабочей гранью снизу. Окно о правиле семи стоит на уровне 4, где применить его не к чему.
- Без удержания кратчайшее решение то же на 21 уровне из 22 досчитанных; на уровне 13 оно длиннее на ход. Уровень 22 решатель не досчитал.
- Любая цепочка требует сойти с уходящего комбо на стоящую кость: игрок стоит на кости, которой собрал комбо, а катить её уже нельзя. Уровень 3 без этого не пройти.
- На пол игрок может попасть с уровня 3; окно о поле стояло на уровне 13.
- Шаг без возврата с выбором из нескольких костей в решениях встречается на четырёх уровнях: 8, 12, 16, 23.

Поиск досок под удержание (`node scripts/teach.mjs hold size=3 dice=5 seeds=300`):

| Доски | Разложено | Решено | Без удержания длиннее | Из них на два хода и больше | Без удержания не пройти |
|---|---|---|---|---|---|
| 3×3, 5 костей, тройки | 477 | 427 | 34 | 0 | 0 |
| 4×4, 6 костей, тройки | 69 | 43 | 2 | не считалось | 0 |

## 8. Что собрано в коде

- Тексты окон голосом лаборанта и памятки для `RULES`: `src/ui/i18n.ts`; сообщения и чужие слова в них — `src/levels/voices.ts`.
- Окно говорит по сообщению за раз, крупными буквами, и печать слышна: `levelIntroPanel` в `src/shell/panels.ts`, `SAY_LARGE_TALL` и `SAY_LARGE_WIDE` в `src/shell/screens/panel.ts`, звук `typed` в `src/audio/score.ts`.
- Перечень уроков по порядку и правила, которые можно перечитать на уровне: `LESSONS`, `lessonsAt` в `src/levels/rules.ts`.
- `RULES` в паузе уровня, по три памятки в окне: `levelRulesPanel` в `src/shell/panels.ts`, `showLevelRules` в `src/app/game.ts`.
- Строка тупика с числами: «Тупик: костей осталось 1, а на комбо нужно 3».
- Отметка шага без возврата появляется с уровня, чьё окно говорит о ходьбе по комбо; пока такого уровня нет — с третьего, как было.
- Мерило уроков: `scripts/teach.mjs`.

Чего нет, пока нет досок: окон `lessonWalk`, `lessonHold`, `lessonClimb` в игре. Рецепты мест (`src/levels/recipes.ts`) и уровни (`src/levels/levels.ts`) не тронуты: их пересобирает «Генерация».

Не проверено: как тексты читаются на телефоне в руке; как звучит печать — её числа проверены тестом, ушами её никто не слушал.

## 9. На что опирается

- Одна новая идея на уровень; первый уровень с ней нельзя пройти мимо неё — [разбор Patrick's Parabox](https://siddarthrg.substack.com/p/tutorial-design-of-patricks-parabox), [комментарии разработчиков Portal](https://theportalwiki.com/wiki/Portal_developer_commentary).
- Ввести в безопасности, развить, перевернуть, сочетать — [Коити Хаясида, Nintendo](https://www.gamedeveloper.com/design/the-secret-to-i-mario-i-level-design).
- Текст до действия слабее подсказки в момент нужды — [Andersen и др., 2012](https://grail.cs.washington.edu/wp-content/uploads/2015/08/andersen2012tio.pdf). Поэтому окно говорит одну мысль, а доска тут же её требует.
- Ошибку объясняют причиной — [Moreno и Mayer, 2005](http://rapunselshair.pbworks.com/f/Moreno_2005.pdf). Отсюда числа в строке тупика.
- Не больше восьми слов на экране — [Джордж Фан](https://notes.hamatti.org/Sources/Talks/How-I-got-my-mom-to-play-through-Plants-vs.-Zombies). Черновики длиннее: это вопрос к правке текстов.
- Не наказывать, пока учишь — [Селия Ходент, GDC 2016](https://archive.org/details/GDC2016Hodent). Отсюда требование к доле прохождений на уровнях с окном.

Остальные источники и оговорки по надёжности — в [VI_Tutorial_Research.md](VI_Tutorial_Research.md).
