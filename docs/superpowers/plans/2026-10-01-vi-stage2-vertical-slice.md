# VI, этап 2: вертикальный срез — план реализации

> Исполняется инлайн в той же сессии. Шаги отмечаются чекбоксами.

**Goal:** готовый визуал «оккультного настольного прибора», единый UI, стадии ритуала по счёту, звук на синтезированных заглушках, reduced motion; сборка пригодна для плейтеста на friends & family.

**Architecture:** правила не меняются. Рендер получает тему и «режиссёра ритуала», который по счёту и событиям тика выдаёт параметры сцены. Звук — отдельный модуль на WebAudio без ассетов, слушает те же события.

**Spec:** [RITE_Design_MVP.md](../../RITE_Design_MVP.md), раздел 12, и [отличия](../specs/2026-10-01-vi-mvp-design.md).

## Global Constraints

- Эффекты только визуальные и звуковые: цифры, ориентации, таймеры, столкновения и камера не меняются; replay не затрагивается.
- Значение куба читается без bloom; точки остаются точками, не сигилами.
- Пороги стадий без ×10: 100, 300, 700, 1500, 3000; каждый срабатывает один раз за партию, переход 1–2 с без паузы.
- Без динамических теней и постобработки; DPR ≤ 1.5.
- Нажимаемые цели ≥ 44 CSS px, основной текст ≥ 14 CSS px.
- Опасность заполнения имеет собственный ритм и цифру и не сливается с декоративным красным.
- Reduced motion: без тряски и пульсаций, стадии остаются различимы через разметку, цвет и звук. Есть mute.
- Все ресурсы внутри сборки (шрифт бандлится), внешних запросов нет.

## Стадии ритуала

| Стадия | Score | Сцена | Звук |
|---|---|---|---|
| 0 | 0 | тихая плита | сухие удары |
| 1 | 100 | разметка по периметру плиты | первый слой дрона |
| 2 | 300 | красные линии между клетками; точки отвечают на очистку общей вспышкой | второй слой |
| 3 | 700 | кубы слабо «дышат» светом; редкие низкие пульсации | низкий пульс |
| 4 | 1500 | геометрическое кольцо вокруг плиты; фон тревожнее | диссонирующий слой |
| 5 | 3000 | короткий фазовый сдвиг, линии складываются в печать, остаётся новая атмосфера | смена тональности |

Рядом со счётом — знак из пяти засечек (заполняется по стадиям) и подпись следующего порога; после последней стадии подписи нет.

## Задачи

### Task 1: режиссёр ритуала
- [x] `src/app/ritual.ts`: `stageForScore(score)`, `nextThreshold(score)`, класс `Ritual` с плавными уровнями 0..1 для каждой стадии и одноразовым событием перехода.
- [x] Тесты: границы порогов, монотонность, сброс в новой партии, однократность перехода.

### Task 2: сцена
- [x] Тема `OCCULT_THEME`; процедурные текстуры: пепельная плита с гравированной сеткой, грани кубов с точками, маска свечения точек.
- [x] Кубы со скруглёнными рёбрами; состояния idle / rising / sinking; карминовое свечение точек при sinking; точечный свет у реакции.
- [x] Фигура из примитивов (ряса-конус и голова), силуэт сквозь кубы.
- [x] Слои стадий: периметр, линии клеток, кольцо, печать; дыхание; фон; фазовый сдвиг.
- [x] Рамка опасности по периметру плиты с собственным ритмом.
- [x] Лёгкая тряска на цепочке, отключаемая.

### Task 3: звук-заглушки
- [x] `src/audio/engine.ts`: шаг, блок, появление, очистка, цепочка (выше с каждым звеном), Happy One, удаление, падение, предупреждение, переход стадии, конец партии, слои дрона по стадиям.
- [x] Старт AudioContext по первому жесту; mute; пауза глушит звук.

### Task 4: интерфейс
- [x] HUD: SCORE, BEST, знак стадии и следующий порог, пауза, отсчёт заполнения.
- [x] Печать ориентации как гравированный знак (SVG): круг, вписанный ромб, текущая грань в центре, четыре превью; подсветка ребра по жесту; режим кнопок.
- [x] Пауза с переключателями звука и движения; результат (SCORE, BEST, MAX CHAIN, TIME, AGAIN, RECORDS); локальные рекорды SCORE / CHAIN / SURVIVAL строгим реестром.
- [x] Подсказки в том же стиле.

### Task 5: проверка
- [x] `npm test`, `npm run build`; размер сборки.
- [x] В браузере на ширине телефона и ПК: читаемость граней на всех стадиях, опасность против декора, reduced motion, mute.
