## Типы

`src/levels/plot.ts`:

```ts
export type Side = 'top' | 'south' | 'east' | 'north' | 'west' | 'under';
/** Как кость приходит на клетку события. Назад — её откат. */
export interface Coming {
  /** Ходы по порядку: `r` перекат, `p` толчок. Либо `by` и `rolls`: столько-то ходов одного вида. */
  seq?: string;
  by?: 'roll' | 'push';
  rolls?: readonly [number, number];
  line?: 'straight' | 'turn' | 'any';
  /** Сколько перекатов уводят кость дальше от клетки события, ровно. Нет — сколько выйдет. */
  away?: number;
  /** Где рабочая грань на старте; нет — где выйдет. */
  starts?: readonly Side[];
}
export interface PlotDie { name: string; face: number; event: number; comes?: Coming; fixed?: boolean }
export interface PlotEvent { kind: 'combo' | 'link' | 'ones'; by: string; spare?: number }
export type Lesson =
  | { kind: 'keeps'; after: number; moves: readonly [number, number]; slack?: number }
  | { kind: 'bait'; at: number; move: 'event' | 'greedy'; fate: 'dead' | 'longer'; depth?: readonly [number, number]; over?: number }
  | { kind: 'safeFirst' };
/** Ворота ступени 3: мерила шкалы. */
export interface Want {
  d?: readonly [number, number];
  rank?: number;          // наименьший rank
  forks?: number;         // не меньше
  ways?: number;          // waysLong не меньше
  hidden?: readonly [number, number];
  /** Похожесть к доскам ряда ниже SIMILAR_ROW и ядро не повторяет ни одно место (правило 16). По умолчанию да. */
  novel?: boolean;
  /** Доски, против которых новизна не судится: источник углубления. */
  instead?: readonly string[];
}
export interface Plot {
  name: string;            // слово пачки: BATCH_WORD
  size: number;
  holes?: readonly { x: number; z: number }[];
  floor?: boolean;         // нет — открыт
  faces?: readonly number[];  // грани доски для файла; нет — грани костей
  dice: readonly PlotDie[];
  events: readonly PlotEvent[];
  figure?: readonly string[];
  pinned?: boolean;
  /** Имя кости, на которой стоит игрок; нет — `o`, если есть, иначе любая нефиксированная. */
  start?: string;
  lessons?: readonly Lesson[];   // safeFirst — по умолчанию; `lessons: []` снимает
  needs?: readonly Technique[];  // в кратчайшем пути обязаны быть
  avoid?: readonly Technique[];  // не должны
  want?: Want;
  brief?: string;          // строка для заметки файла
}
```

Функции `plot.ts`: `checkPlot(plot): string[]` (ошибки: событие без костей, `by` не в своём событии, у комбо меньше `face` костей, звено не одной кости, фиксированная с `comes`, фигура не по костям), `plotOfBoard(spec, opts?)`, `varyPlot(plot, vary)`, `plotLength(plot)` — `[min, max]` ходов.

## Ступени работы

Каждая ступень кончается зелёными `npx vitest run <свои тесты>`, `npm run typecheck`; в конце — полные проверки.

### 1. `plot.ts` и `plotOfBoard`

`plotOfBoard(spec, way = spec.solution)`: играет путь (`tellMove` из `src/rules/levelSolver.ts`, кубы по `id` в порядке `layout.dice`), для каждой кости — ходы, которыми она двигалась до своего ухода (`seq` из `r`/`p`, `line`, `away`), событие, в котором ушла (`event` — номер хода с событием среди ходов с событиями), `face` — верх в момент ухода; события — ходы со `scoreOf(...).beats[i].event !== 'none'`, `by` — кость, которой сделан ход, `spare` у звена; фигура — клетки событий, рамка по доске (`pinned: false`); `start` — кость под игроком; `fixed` — с доски; `size`, `holes`, `floor`, `faces` — с доски; `lessons` — `safeFirst`, если `safeFirstOf` доски да, иначе `[]`; `want.instead` — `[spec.id]`. Доска с уходящими костями или стартом на полу — ошибка «замысел с такой доски не снимается».

`varyPlot(plot, vary)`: `vary` — `{ rolls?: number; grow?: 'link' | 'die'; face?: Record<number, number>; turn?: boolean }`. `rolls: 1` — у каждой приходящей кости диапазон ходов шире на один вверх (`seq` → `by`/`rolls`, если ходы одного вида); `face` — замена граней (`{2: 3}`; у комбо костей добавляется до новой грани, имена `a1`, `a2`…, без `comes`); `grow: 'link'` — звено ещё одной кости той же грани к последнему комбо, приходит одним-двумя перекатами; `turn` — фигура не закреплена (по умолчанию и так). Тест: на `act-k23`, `act-k25`, `hidden-face-1` замысел проходит `checkPlot`, длина `plotLength` равна `par`, кости и грани сходятся с доской.

### 2. `layBack.ts`: кладка назад

`layBack(plot): Space`, где

```ts
interface Space { total: number; at(index: number): Laid | null; }
interface Laid { spec: LevelSpec; length: number; placement: number }
```

1. **Положения фигуры** — с фигурой: все сдвиги (и восемь поворотов/отражений, если не `pinned`), где клетки фигуры на поле и не на вырезах; повторы по множеству клеток с именами убираются. Без фигуры: события по порядку — комбо `n` костей — связный кусок из `n` свободных клеток (для первого — где угодно, для следующего — где угодно, вне клеток прежних событий), звено — клетка рядом с клетками своей цепочки (комбо и прежние звенья), единицы — кость звена рядом с цепочкой и стоящие единицы в любых свободных клетках. Перебор глубиной до 50 000 положений; больше — положения берутся случайно по зерну (`Space.sampled`).
2. **Откаты** — для каждой кости с `comes` при данном положении: все пути назад (направление ухода на каждом шаге), длины из `rolls` (или `seq`), с `line` (`straight` — одно направление; `turn` — хотя бы одна смена), `away` (счёт шагов вперёд, после которых кость дальше от клетки события по Манхэттену); перекат назад: клетка `+dir`, `ori = roll(ori, dir)`; толчок назад: клетка `+dir`, грань та же. Шаг на край или вырез — путь отпадает. Ориентация в момент события: верх — `face`, на север — любая из четырёх. Кость без `comes` стоит на клетке события гранью вверх, север — любая из четырёх. `starts` — фильтр пути по стороне рабочей грани на старте.
3. **Индекс пространства** — смешанное основание: положение × (пути × север) каждой кости × выбор старта. `total` — сумма по положениям. `at(i)` собирает доску; `null` — стартовые клетки совпали.

Тест: `layBack(plotOfBoard(act-k23))` содержит доску `act-k23` с точностью до `normalSpec` (полный перебор, поиск по ключу); то же `act-k25`. `total` `act-k23` — меньше 200 000.

### 3. `plotJudge.ts`: ступени 0–2

`judgeLaid(plot, laid, opts): Judged` — первая несдержанная проверка — причина (`reason: string`, ключ для счёта), ступень, до которой дошла доска, и что посчитано.

- **0. Раскладка.** Готовой группы нет (`hasReadyGroup` по верхам); единица сверху только у костей событий `ones`; правила принимают доску (`levelConfig`/`createRun` без исключения — `src/rules/level.ts` бросает на битой); не повтор (`normalSpec` в `Set` прогона); `want.hidden` — число костей без фиксированных, чья рабочая грань не `top`/`south`/`east` на старте.
- **1. Путь.** `solveLevel(spec, { maxMoves: laid.length, maxStates: opts.states ?? 20000 })`. Нет пути: `exhausted` — «длиннее задуманного», иначе «решатель сдался». `par < length` — «есть путь короче» с подробностью: какая кость сделала меньше ходов, чем задумано. `par === length`: путь проигрывается с учётом костей (как в `plotOfBoard`): события те же по порядку, видом и костью `by`; каждая кость уходит в своём событии; `spare` звена, если задан; `needs`/`avoid` против `solution.uses`. Иначе «события иные».
- **2. Урок.** `safeFirst` (`safeFirstOf`), `keeps` (`keepsOf`), `bait` (`baitOf`) — в `src/levels/measures.ts`:
  - `keepsOf(spec, way, after, slack = 0): { keeps: number; dead: number; deadLater: number; detour: number; longestDetour: number }` — положение после события `after` (номер события на пути), каждый ход из него — `movesOf` (`src/levels/labText.ts`) с `after`;
  - `baitOf(spec, way, at, move, fate): { bait: boolean; depth: number | null }` — ход вида `event` (после него сразу уходит что-то) или `greedy` (ход `GREEDY` персоны), которого нет на пути, после `at` ходов пути; глубина — как `trapDepthOf` (`src/levels/orders.ts`).

Тест: `act-k23` — после комбо держит один ход (`keepsOf(..., 0).keeps === 1`); `act-k25` — приманка второго хода ведёт в тупик. Обе доски проходят ступени 0–2 по своим замыслам из `plots.ts` (замыслы спеки, раздел 3.3, переписанные в `Plot`).

### 4. Ступень 3, финалисты, паспорт

`finalOf(plot, spec, opts): Passport` — мерила: `par`, `route`, `kind`, `rank` (`rankOf(rankShares(spec, runs))`, `runs` 30), `shares`, `reader` (`shareOf(spec, READER, runs)`), `depth` (`depthOf`), `hidden` (`hiddenOf`), `D` (`difficulty`), `firsts` (`firstsOf`), `sig` (`coreKey(coreOf(spec))`), `nearest` — ближайшая доска ряда (`R` в `boards/row.json`, исключая `want.instead`) и похожесть, `sameCore` — место ряда с тем же ядром, уроки ступени 2 (с тремя числами `keeps`), `misses` — ворота `want`, которых доска не держит (`D вне 7–8`, `rank 3 < 5`, `похожа на P09 0.81`). Ворота по умолчанию: `novel: true`.

**Выбор финалистов** (`pickFinalists(passed, final)`): форма доски — клетки костей и сторона рабочей грани каждой кости, с точностью до сдвига (`shapeOf`); сначала по одной на форму, внутри формы — в порядке случайном по зерну; до `final` (40).

**Порядок выдачи** (`rankPassports`): меньше `misses` — выше; при равенстве — ближе `D` к середине `want.d`, больше `waysLong`, меньше `longestDetour`; доска с обходом длиннее 6 после одной ошибки — в конец с пометкой `обход N`. `keep` (10) лучших — файлами.

**Файл:** `batchFile` (`src/levels/labText.ts`) с словом `plot.name`, статус `N`, заметка `замысел <name>, круг <k>: <brief>`, `faces`, `par`, `exact: yes`, `way`. Паспорт — `boards/out/lay/<name>/passport-<k>.txt` и `.json`.

### 5. `scripts/lay.mjs`

```
node scripts/lay.mjs lay plot=<имя> [from=<доска>] [vary=rolls1,link,face2-3] [workers=6] [limit=200000] [seed=1] [states=20000] [upto=laid|path|lesson|final] [final=40] [keep=10] [round=N] [dry] [json]
node scripts/lay.mjs passport file=<доска> [json]
node scripts/lay.mjs plots
```

`plot=` — замысел из `PLOTS` (`src/levels/plots.ts`); `from=` — замысел с доски (`plotOfBoard`, имя замысла — `<доска>-deep`), `vary=` — `varyPlot`. Процессы — как `shareOut` в `scripts/level.mjs`: процесс `i` из `n` берёт индексы пространства `i, i+n, …` (при выборке — индексы по зерну, перемешанные), пишет `boards/out/lay/<name>/lay-<i>.jsonl` и в stdout строки JSON: счёт по ступеням и причинам, прошедшие ступень 2. Раз в 5 с — строка хода в stderr. Главный процесс выбирает финалистов, второй раз раздаёт их процессам на ступень 3, ранжирует, пишет файлы и отчёт `boards/out/lay/<name>/report-<k>.txt` (образец — спека, 7.2) со строкой «находки»: приём, который есть у всех прошедших ступень 1 (`uses`), и ступень, где не осталось ничего. Код выхода: 0 — записаны; 1 — ни одна не прошла ступени 2 (ближайшие — в отчёте); 2 — замысел не читается; 3 — два «убрать» подряд у пачки замысла (ступень 7).

### 6. Замыслы `plots.ts`

`PLOTS: Record<string, Plot>`:

- шесть замыслов досок актов (`act-k17`, `act-k21`, `act-k22`, `act-k23`, `act-k25`, `act-k28`) — для тестов; пишутся по доскам и спеке, раздел 3;
- брифы спеки пересборки 31–100, раздел 5: `wall` («Стена»), `stop` («Упор»), `far-faces` («Две далёкие грани»), `three-tricks` («Три приёма»), `finale` («Финал»), `snowball` («Сноубол позже»), с `want` по их «Проверке».

Тест: каждый замысел проходит `checkPlot`; у шести досок актов `layBack` находит саму доску.

### 7. Круг: отметки владельца

Пачка замысла — файлы `boards/<name>-<n>.txt` с `batch: <name> …`. Отметки мастерской — статус файла: `RC` хорошая, `D` доделать, `X` убрать. `lay` следующего круга: доски пачки, которые он отметил, сводятся с паспортами по `cacheKey`; формы досок `X` не выдаются; среди прошедших ступень 3 выше стоят ближние к `RC` по мерилам паспорта (`par`, `D`, `forks`, `hidden`, число костей, `waysLong`), приведённым к одной шкале; две последние отмеченные доски пачки обе `X` — выход с кодом 3 и строкой «два убрать подряд — спросить о замысле». Тест на временной папке.

### 8. Кнопка «ещё десять» в мастерской

Строка пачки в списке «новые» (`src/lab/workshopLists.ts`, `workshopListView.ts`) получает кнопку «ещё десять», если у пачки есть замысел (`PLOTS[batch]` или `from`): страница зовёт `POST /__boards/lay` плагина дев-сервера (`vite.boards.ts`, `src/lab/boardsServer.ts`), тот запускает `scripts/lay.mjs lay plot=<имя> keep=10` и отвечает, когда файлы записаны; список перечитывается. Секунды спеки (воркеры в браузере) — не в этом плане: на кнопке ответ — минута, отчёт виден в `boards/out/lay/`. Проверка в preview.

### 9. Работа: доски для пересборки

Замыслы раздела 6 кладутся по кругу: прогон → отчёт → правка замысла по причинам отказа → прогон, пока у каждого брифа не будет десяти финалистов без `misses` или отчёт не скажет, почему их нет. Пачки остаются статусом `N` для мастерской. Каждая пачка — строка в «Что вышло иначе»: замысел, пространство, воронка, `D`/`rank` финалистов, сколько держат ворота.

## Что вышло иначе

Ступени 1–3 (28 октября 2026):

1. **`PlotDie.on`** — новое поле: кость кончает путь на клетке кости прежнего события (накат на уходящую). У `act-k25` тройка накатывается на уходящую двойку: две кости уходят с одной клетки, и фигуру без этого поля не нарисовать.
2. **`act-k25` больше не держит приманку.** Её поворот (комбо троек на втором ходу теряет доску) пропал в 0.2.66, когда заработали все грани: путь сменился, пар 6 → 5, после `3,3,W` комбо `1,3,N` по-прежнему очищает доску в пар. Тест держит, что доска останавливается на ступени 2 с причиной `bait`; путь приманки проверен на `trap-5` (приманка первым ходом, глубина 0, как у `trapDepthOf`). Спека генератора, спека кампании и заметка `act-k25` всё ещё говорят о ловушке, которой у доски нет.
3. **Толчок назад** отпадает, если клетка за костью (где стоит игрок) — край или вырез, как у `slideAway` в `route.ts`.
4. **Одинаковые откаты** (та же стартовая клетка, ориентация и длина) считаются один раз.
5. **`plotOfBoard`** ставит `line` только путям из одних перекатов длиной от двух, `away` — как в пути доски; исходная доска всегда лежит в своём пространстве.
6. **Жадная приманка**: `baitOf` с `move: 'greedy'` берёт лучшие ходы `GREEDY` двенадцатью зёрнами `personaMove` (цена хода персоны не экспортирована).
