## 3. Проверки перед архивом

По [чеклисту Playgama](https://wiki.playgama.com/playgama/mcp/game-checklist.md) (`get_game_checklist`), пункты, которых никто не проверял после кампании:

- Окно 2:1 и квадрат 800×800: меню сжимает кости ([VI_Owner_Words.md](../../VI_Owner_Words.md), раздел 7).
- Матрица размеров: 360×640, 390×844, 915×412, 1280×720, 2560×1440 — интерфейс не наезжает, текст читается.
- Долгое нажатие на поле не выделяет текст и не открывает меню браузера.
- Уход в фон и возврат, поворот экрана, реклама — партия и звук не сбиваются, прогресс не теряется.
- Опубликованную ссылку песочницы открыть и пройти то же самое там.
- `npm test`, `npm run typecheck`, `npm run build`, `node scripts/docs-check.mjs`; `npm run pack -- playgama`; загрузка — после «ок» владельца.
