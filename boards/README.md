# boards — мастерская досок

Доски уровней как текстовые файлы, по файлу на доску: их читают и пишут страница `?lab=levels`, команда `node scripts/level.mjs` и агент в редакторе. Формат, команды и правила папки — [docs/VI_Levels_Lab.md](../docs/VI_Levels_Lab.md).
В игру доска отсюда сама не попадает: в `src/levels/levels.ts` и `src/levels/road.ts` её переносят руками, по слову владельца.
